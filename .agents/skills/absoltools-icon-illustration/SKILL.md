# AbsolTools icon illustrations

Read `plaintool-network/ILLUSTRATION_GUIDE.md` before making assets. The user-provided 12-icon reference set from 2026-10-24 establishes the visual direction: a single lavender-to-violet vertical gradient, bold filled silhouettes, deliberate transparent cutouts, and geometrically consistent repeated parts. Use the references as a grammar; do not trace or redistribute the example images.

For each tool, name the subject and the operation in one sentence before drawing. Give the subject a clear silhouette, then add the smallest operation cue needed to distinguish adjacent tools. Avoid generic file badges, extra plus/check/sparkle marks, thin strokes, category-specific colors, glossy layers, or a cluster of tiny details. Where a label is essential, such as `PDF` or `123`, keep it readable at the shipped size and do not substitute an Adobe trademark.

Construct SVG on the 128 × 128 artboard in the guide. Align repeated cutouts and modules to one grid; QR finder shapes must match, and the data cells must all share one size. Prefer transparent negative space to white paint. A generated bitmap can help explore a silhouette, but it must be translated into the approved geometry and reviewed as a final project asset before use.

Render the complete icon row at 72 px desktop and 56 px mobile on light and dark cards. Inspect an RTL locale, compare all icons together, and fix irregular spacing or ambiguous cues. Verify the SVGs parse, load locally, and introduce no external requests. Save browser captures with the task's QA notes. The project UI review skill supplies the server and browser verification workflow.

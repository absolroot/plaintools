# 기능 경쟁력 리뷰 기록

이 폴더는 AbsolTools 기능이 어떤 문제를 해결하도록 개선되었는지, 경쟁
도구와 비교해 무엇이 강하고 부족한지, 다음 업그레이드가 무엇인지 추적하는
내부 제품 기록이다.

## 운영 규칙

- 날짜별 폴더를 만들고 기능군마다 한 파일을 둔다.
- 현재 구현 주장은 코드, 테스트, Git 커밋 중 하나 이상의 근거를 남긴다.
- 경쟁 도구 주장은 확인 날짜와 직접 URL을 남긴다.
- `더 빠름`, `더 안전함`, `최고`, `모든 형식 지원` 같은 비교 우위 표현은
  측정 범위와 재현 방법이 없으면 사용하지 않는다.
- 브라우저 로컬 처리, URL 비노출, Worker 격리처럼 코드로 확인 가능한
  속성과 주관적인 UX 우위는 구분한다.
- 개선 후보는 `P0`(즉시 차단)부터 `P3`(장기 확장)까지 우선순위를 매기고,
  실제 반영 시 커밋과 재검증 결과를 같은 문서에 추가한다.
